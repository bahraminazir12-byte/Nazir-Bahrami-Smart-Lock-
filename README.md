# NAZIR BAHRAMI SMART LOCK

Android starter project for an in-app QR identity demo.

## Build on GitHub
1. Upload this project to a new GitHub repository.
2. Open **Actions**.
3. Run **Build Nazir Bahrami Smart Lock APK**.
4. Open the completed workflow run.
5. Download the artifact **Nazir-Bahrami-Smart-Lock-APK**.
6. Extract `app-debug.apk` and install it on Android.

The app uses the camera to scan a QR code and checks it against the embedded demo credential.

This is only an in-app QR identity demo. It does not unlock Android's system lock screen, bypass a PIN/pattern/password, or change device security settings.
